# tech-blog

This repository is for learning purposes and follows hands-on blog posts published at [techtroupe.com](https://techtroupe.com).

## What This Repo Is

The code here is organized as practical infrastructure/security examples that map to blog walkthroughs.
You can use each folder independently as you follow the related post.

## Folder Overview

- `verified-access/`
  - Intro stack for AWS Verified Access + Aurora PostgreSQL Serverless v2.
  - Includes OpenTofu configs, sample variables, and setup/troubleshooting notes.

- `security-agent/`
  - Security agent-related code and supporting assets used in related posts.

- `aws-network-firewall/`
  - AWS Network Firewall examples and configuration used in networking/security posts.
